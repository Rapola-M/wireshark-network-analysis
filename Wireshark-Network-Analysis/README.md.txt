# Wireshark Network Traffic Analysis

## Project Overview

This project demonstrates practical network traffic analysis using Wireshark. It focuses on capturing, filtering and examining network packets to understand how different network protocols communicate.

## Objectives

- Capture network traffic using Wireshark.
- Analyse DNS requests and responses.
- Examine TCP communication and flags.
- Analyse UDP packets and ports.
- Capture ICMP Echo Requests and Replies.
- Examine IPv4 traffic.
- Understand network protocols using Protocol Hierarchy.

## Tools Used

- Wireshark
- Windows Command Prompt
- Windows operating system
- Web browser

## Protocols Analysed

| Protocol | Purpose |
|---|---|
| DNS | Resolves domain names into IP addresses |
| TCP | Provides reliable data transmission |
| UDP | Provides connectionless data transmission |
| ICMP | Supports network diagnostics |
| IPv4 | Provides addressing and routing |
